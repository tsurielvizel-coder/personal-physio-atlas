### מה אני רוצה שתעשה בשלב ראשון (יישור קו לפני יצירת 51 קבצים)
1. בדוק אילו כלים/ספריות זמינים אצלי בסביבה בפועל (Python, `ffmpeg`, `Pillow`, Blender, Node וכו') או גישה לאינטרנט להורדת נכסי קוד פתוח / מודל 3D.
2. הצע והשווה בקצרה את האפשרות הריאליסטית הטובה ביותר שעובדת בפועל במחשב הזה — לדוגמה:
   - צינור Python אופליין שמוריד/ממיר ומנרמל צילומי או סרטוני גבר אמיתי ממאגרים חופשיים (כגון `free-exercise-db` ב-Unlicense) ללופי WebP/MP4 קלילים; או

   - שילוב `Three.js` / `<model-viewer>` עם שלד גבר 3D אחד ו־51 אנימציות שניתנות לסיבוב 360°; או
   - לופים מפוקחים של וידאו/מדיה מעובדים ב-Python + `ffmpeg`.
3. אשר איתי איזו מהאפשרויות הכי נראית לי לפני שאתה מפיק את כל 51 הנכסים — או תדגים קודם על 3–5 תרגילים מייצגים (`bird_dog`, `lying_leg_raise`, `diamond_pushup`, `bulgarian`, `suitcase_carry`) כדי שאראה את האיכות בעיניים!

### דרישות טכניות והנדסיות חובה
1. שמור על החוזה הציבורי הקיים של `window.AtlasAnimator`:
   - `mount(containerEl, animKey, options)`
   - `unmount(containerEl)`
   - `clearDetached()`
   - `setSpeed(mult)` (`0.7x / 1x / 1.3x` -> שינוי `playbackRate` בווידאו או מהירות ב-3D)
   - `setPaused(paused)` ו-`isPaused()`
2. שלב מנגנון `Graceful Fallback`: כל תרגיל שיש לו קובץ מדיה ב־`tracker/assets/exercises/` יוצג דרכו (עם `poster`, `autoplay loop muted playsinline`, ו-`IntersectionObserver` לחיסכון בסוללה בנייד), וכל תרגיל שעדיין חסר ייפול אוטומטית למנוע ה-SVG הקיים בלי שום שגיאה.
3. שמור על תאימות מלאה גם בפתיחה ישירה מהמחשב (`file://`, ללא שרת ועם מניפסט JS תואם) וגם באתר החי ב־GitHub Pages, ובמשקל קל ומהיר לסלולרי (עד ~250KB לתרגיל).
4. שדרג בהתאמה את כרטיסי התרגיל ומסך המאמן (`tracker/styles.css`, `tracker/app.js`) לאסתטיקה נקייה ברמת Google Play (אופציה לבדיקת זווית/זום, אינדיקציית שריר, ונגן חלק במצב מאמן).
