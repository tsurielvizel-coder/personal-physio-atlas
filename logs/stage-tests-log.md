# לוח מבחני מעבר שלבים (Stages 1–10 Scorecard)

כאן מתעדים את מבחן השיבוץ ההתחלתי ואת תוצאות מבחני המעבר בין שלבים.
**תנאי ברזל לכל מעבר שלב:**
1. עמידה בכל יעדי הביצוע של השלב.
2. פער ימין-שמאל: **<= 15%** בשלבים 1–4, ו-**<= 10%** בשלבים 5–10 (קריטי בגלל העקמת הקלה והאקדח).
3. מדד כאב ירוק: מקסימום 2/10 במאמץ ו-**0 החמרה בגב ב-24 השעות שאחרי המבחן**.
