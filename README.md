# תכנית אטלס-פיזיו: גב ברזל, מילואים וחיוניות (10 שלבים)

מאגר מקצועי, מדעי ומודולרי המשלב **פיזיותרפיה אורתופדית מבוססת-ראיות**, **קליסתניקס מדורג (בהשראת שיטת Atlas Calisthenics)**, ו**מדע ההתמדה והחיוניות** — מותאם אישית לבן 28 בריא עם עבודה משרדית, עקמת קלה, אירוע כאב מהליכה עם אקדח, ויעד מוכנות למילואים.

> **התחלה מהירה ב-60 שניות:**
> 1. פתח את אפליקציית המעקב המקומית בדפדפן (עובדת אופליין בלי התקנות): [tracker/index.html](tracker/index.html)
> 2. בצע את **מבחן השיבוץ (5 דק')** מתוך [מדריך 10 השלבים](docs/03-ten-stages-roadmap.md) כדי לדעת אם להתחיל בשלב 1 או גבוה יותר.
> 3. בכל שבוע בחר בין **מוד `+30 דק'`** (שבוע עמוס) ל-**מוד `+60 דק'`** (אופטימלי), וביום לחוץ הפעל **מוד חירום של 5 דקות**.

## עיקרי התכנית והשדרוגים המיידיים

| תחום | מצב קיים | השדרוג בתכנית החדשה |
|---|---|---|
| **תרגילי הרצפה שלך (3×/שבוע)** | Bird-Dog, פלאנק 35 שנ', קוברה, הרמות אגן בצד, **הרמות רגליים בשכיבה (ידיים מתחת לטוסיק)** | שדרוג ה-Bird-Dog לעצירת 3–5 שנ', פלאנק RKC, ופלאנק צידי סימטרי. **החלפת הרמות הרגליים המסוכנות** (כוח גזירה מהפסואס לפי McGill) ברצף בטוח של **Dead Bug → Hollow Body**. |
| **תוספת זמן גמישה** | אין מסגרת תוספת מוגדרת | שני מסלולים קבועים בלי "הכול או כלום": **`+30 דק'/שבוע`** (3×10 דק' אחרי הרצפה או 2×15 דק') ו-**`+60 דק'/שבוע`** (3×20 דק'), + **5 דק' חירום**. |
| **עקמת קלה ואקדח** | רגישות וכאב בהליכה ממושכת עם אקדח | חוק סימטריה מדיד ($\le 15\%$ -> $\le 10\%$), התחלה תמיד מהצד החלש, ותרגול ספציפי של **Suitcase Carry** (4 עד 20 ק"ג) + התאמות חגורה ונרתיק. |
| **מוכנות למילואים** | מעבר חד מעבודה בישיבה למאמץ טקטי | חשיפה מדורגת לצעדות משקל (כל 10–14 יום, 6 עד 20 ק"ג) לצד סיבולת זוקפי גב (**Biering-Sørensen** עד 120 שנ') וכוח רגליים חד-צדדי. |
| **חיוניות וערנות בעבודה** | עייפות וקיבעון מישיבה ממושכת | 4 **חטיפי תנועה של 90 שנ'** (היענות מחקרית של 82%–91%), שמירה על מאמץ מהנה בזמן האימון (RPE 7–8) ושימור השחייה (30 דק' חתירה). |

## העלאה ל-GitHub ופתיחת אפליקציית המעקב ב-GitHub Pages

המאגר כבר מאותחל מקומית עם Git (`main`). כדי לגבות אותו ב-GitHub ולהריץ את האפליקציה גם מהטלפון בכל מקום:

```powershell
# 1. התחברות לחשבון GitHub (פעם אחת)
gh auth login

# 2. יצירת מאגר פרטי (או ציבורי) ודחיפת הקוד
gh repo create personal-physio-atlas --private --source=. --remote=origin --push
```

> **טיפ לשימוש בנייד:** אם תגדיר את המאגר כציבורי (או תפעיל GitHub Pages דרך `Settings -> Pages -> Deploy from branch: main / root`), תוכל לפתוח את `/tracker/` מכל סמארטפון כשאתה בפארק או במילואים! בנוסף, הממשק כולו שומר נתונים בדפדפן (`localStorage`) וכולל כפתור ייצוא/ייבוא לקובץ JSON.
