# תכנית אטלס-פיזיו: גב ברזל, מילואים וחיוניות (10 שלבים + אפליקציית מאמן מודרך)

מאגר מקצועי, מדעי ומודולרי המשלב **פיזיותרפיה אורתופדית מבוססת-ראיות**, **קליסתניקס מדורג (בהשראת שיטת Atlas Calisthenics)**, **אפליקציית אימון מודרך עם הדמיה אנטומית והדרכה מלאה לכל תרגיל**, ו**מדע ההתמדה והחיוניות** — מותאם אישית לבן 28 בריא עם עבודה משרדית, היפר-לורדוזיס מותנית קלה ממש, ויעד מוכנות למילואים.

> **התחלה מהירה ב-60 שניות:**
> 1. פתח את **האפליקציה באוויר (לפלאפון ולמחשב):** https://tsurielvizel-coder.github.io/personal-physio-atlas/tracker/ *(או מהכתובת הראשית שמפנה אליה אוטומטית: https://tsurielvizel-coder.github.io/personal-physio-atlas/ , וכן מקומית אופליין דרך [tracker/index.html](tracker/index.html))*.
> 2. בצע את **מבחן השיבוץ (5 דק')** מתוך [מדריך 10 השלבים](docs/03-ten-stages-roadmap.md) כדי לדעת אם להתחיל בשלב 1 או גבוה יותר.
> 3. בכל שבוע בחר בין **מוד `+30 דק'`** (שבוע עמוס) ל-**מוד `+60 דק'`** (אופטימלי), וביום לחוץ הפעל **מוד חירום של 5 דקות** או לחץ בקליק אחד **"ביצעתי פיזיותרפיה רגילה" / "ביצעתי שחייה"**.

|---|---|---|

| **שישיית הרצפה שלך (3×/שבוע)** | 1) סופרמן (Bird-Dog), 2) בטן סטטית 35 שנ', 3) מיני-קוברה 10 שנ', 4) **דד-באג (3×12/יד)**, 5) פלאנק צידי (אחד לכל צד), 6) **הרמות רגליים בשכיבה (ידיים מתחת לטוסיק) × 12** | **כל ה-6 נשארים בסדר הקבוע שלך!** השילוב שלך של Dead Bug והרמות רגליים מעניק שליטה מצוינת באגן; נוספו דגשי סיבוב אגן לאחור להיפר-לורדוזיס הקלה ומיני-קוברה עדינה. |
| **אנימציות 2.5D ומדריך מלא לכל תרגיל (`v3.2`)** | תרגילים חדשים דרשו הבנה מהירה וברורה יותר | **51 אנימציות אנטומיות ב-2.5D** במבט צד ומבט קדמי כולל הדגשת שריר פעיל, חיצי תנועה וציוד ביתי תואם ([tracker/animator.js](tracker/animator.js)) עם וריאציות ייעודיות (`diamond_pushup`, `decline_pushup`, `pseudo_planche`, `one_arm_incline`, `hspu`), פלוס **אנציקלופדיית הדרכה מלאה בעברית** ([tracker/exercise-guides.js](tracker/exercise-guides.js)): תגית `✨ תרגיל חדש`, מגירת `📖 איך עושים? | **מוזיקה חסידית / צמאה / הרב קוק** | ללא ליווי מוזיקלי | **נגן מוזיקה קבוע בראש המסך:** שילוב ניגוני **פרויקט "צמאה"** והרב קוק מיוטיוב באתר החי, **3 ניגונים חסידיים מובנים באופליין** (Web Audio), וטעינת קובצי MP3 מקומיים. |

| **היפר-לורדוזיס קלה ומילואים** | ישיבה ממושכת + מילואים מתקרבים | חיזוק ישבן והמסטרינגס (גשר, RDL, נורדיק), שחרור מכופפי ירך, צעדות תיק מדורגות (6 עד 20 ק"ג כל 10–14 יום) ו-Suitcase Carry לחיסון המותן למילואים או לנשיאת אקדח עתידית. |

## קישורים ישירים למדריכים

1. **[01. הערכה קלינית-פיזיותרפית ושיטת אטלס](docs/01-clinical-assessment.md)** — פירוק ביומכני של 6 התרגילים שלך (כולל Dead Bug והרמות הרגליים) והתאמה להיפר-לורדוזיס קלה.
2. **[02. תכנית שבועית גמישה (+30 / +60 / 5 דק')](docs/02-weekly-programs.md)** — לוחות זמנים מעשיים לאפס ציוד בבית + מתח חיצוני 1–2×/שבוע.
3. **[03. מפת 10 השלבים ומבחני המעבר](docs/03-ten-stages-roadmap.md)** — מבחן השיבוץ והקריטריונים למעבר משלב לשלב.
4. **[04. מדע ההתמדה והשינוי ההתנהגותי](docs/04-adherence-science.md)** — למה תכניות כושלות ואיך המחקרים מבטיחים הצלחה.
5. **[05. מדריך מילואים ונשיאת ציוד](docs/05-miluim-and-holster-guide.md)** — הכנה הדרגתית לעומס צבאי והגנה לנשיאת אקדח עתידית.
6. **[06. חיוניות ואנרגיה לעובדי משרד](docs/06-vitality-and-energy.md)** — פרוטוקול Puetz & O'Connor וחטיפי תנועה של 90 שניות.
7. **[07. מפת דרכים: הדמיה ריאליסטית ברמת Google Play](docs/07-realistic-exercise-media-roadmap.md)** — איך להחליף את ההדמיות הנוכחיות בהדמיה פוטוריאליסטית / 3D של גבר אמיתי באמצעות Python כפייפליין בנייה או Three.js בדפדפן.
8. **[פרומפט מוכן לצ'אט חדש לשדרוג ההדמיה](docs/NEXT-CHAT-REALISTIC-MEDIA-PROMPT.md)** — טקסט מוכן להעתקה-הדבקה להמשך פיתוח בצ'אט נקי.
9. **[אפליקציית המאמן המודרך](tracker/index.html)** — פתיחה מקומית מיידית (עובד גם ללא אינטרנט).

## העלאה לאוויר (GitHub Pages לסלולרי ולמחשב) + סנכרון ענן

המאגר מוכן להרצה כ-**אפליקציית מובייל (PWA)** עם:
- דף פתיחה אוטומטי ב-[index.html](index.html) וקובצי PWA ב-[tracker/manifest.json](tracker/manifest.json)
- נגן **יוטיוב משולב ואוטומטי** של ניגוני **צמאה**, **הרב קוק (כנפי רוח)** ומחרוזות חסידיות
- **סנכרון אוטומטי דו־כיווני בין הטלפון למחשב** דרך GitHub Secret Gist ([tracker/cloud-sync.js](tracker/cloud-sync.js)) עם שמירה תוך 1.2 שנ' ומשיכה אוטומטית בפתיחה, חזרה לטאב, חזרה לרשת וכל 60 שנ'

האתר כבר פרוש בכתובת:
https://tsurielvizel-coder.github.io/personal-physio-atlas/tracker/

להעלאה ועדכון אוטומטי בעתיד מתוך Windows PowerShell (בתיקיית הפרויקט):
```powershell
powershell -ExecutionPolicy RemoteSigned -File .\deploy-github.ps1
```
*(טיפ ל־Windows: אם `git push` חווה ניתוק HTTP/2 על `schannel`, הרץ `git -c http.version=HTTP/1.1 push origin main`.)*

לאחר פתיחת האתר במחשב, לחץ באפליקציה על **☁️ סנכרון טלפון-מחשב**, צור GitHub Token עם הרשאת `gist` בלבד והדבק אותו פעם אחת, ולאחר מכן העתק את **קישור הצימוד** ושלח לעצמך בוואטסאפ — פתיחתו בטלפון תסנכרן את שני המכשירים אוטומטית מכאן והלאה!
